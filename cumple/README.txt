# 🎂 Página de cumpleaños

Proyecto creado para una página de cumpleaños/amiga.

## Abrir en Visual Studio Code

1. Abre esta carpeta en VS Code.
2. Abre `index.html` con tu navegador.
3. Para una experiencia más cómoda, instala la extensión **Live Server** en VS Code y pulsa:
   `Open with Live Server`.

## Cambiar el mensaje

Todo el texto está en `index.html`.

## Cambiar la foto

Reemplaza:
`images/foto-amistad.jpeg`

por otra foto manteniendo el mismo nombre, o cambia el nombre del archivo en `index.html`.

## Publicarla en Internet

Más adelante puedes subir esta carpeta a GitHub Pages, Netlify o Vercel.

## Novedades
- Música de cumpleaños de fondo (se activa al abrir la sorpresa; botón 🎵 para pausar y 🎉 para cambiar a "modo fiesta").
  Para usar una canción real: pon tu mp3 en una carpeta `music/` y escribe la ruta en `MP3_PATH` dentro de script.js.
- El botón "NO PRESIONAR" ahora se escapa 13 veces, se encoge y tiene barra de progreso.
- Nuevas secciones: velitas para pedir un deseo y cupones de regalo.
